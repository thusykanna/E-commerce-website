## 📌 Overview

The **E-commerce-website** project is a powerful developer tool designed to streamline the creation and management of online stores.

### 💡 Why E-commerce-website?

This project aims to provide a comprehensive solution for building and managing e-commerce platforms with ease. The core features include:

- 🎨 **Responsive Admin Panel:** A dynamic interface for managing operations, ensuring accessibility across devices.
- ⚡ **Modern Tech Stack:** Utilizes React and Vite for fast development, enhancing productivity and user experience.
- 🔗 **Seamless Backend Integration:** Configured for efficient communication with backend services, ensuring smooth data flow.
- 🔒 **Robust Authentication:** Implements secure user authentication and session management, safeguarding sensitive operations.
- 📦 **Comprehensive Order Management:** Facilitates real-time order tracking and management, improving administrative efficiency.
- ✨ **Customizable UI:** Tailwind CSS integration allows for easy styling and customization, enhancing visual appeal.

## 🚀 Getting Started

### ✅ Prerequisites

Ensure you have the following installed:

- **Programming Language:** JavaScript  
- **Package Manager:** npm  
- **Container Runtime:** Docker

---

### 🧰 Installation

#### 1.Clone the repository:

```bash
git clone https://github.com/thusykanna/E-commerce-website
```

#### 2.Navigate to the project directory:

```bash
cd E-commerce-website
```

#### 3.Install the dependencies:

***Using Docker:***

```bash
docker build -t thusykanna/E-commerce-website .
```
***Using npm:***

```bash
npm install
```

#### 4.Run the project:

***Using Docker:***

```bash
docker run -it <image_name>
```
***Using npm:***

```bash
npm start
```

#### 🧪 Testing 

***Using Docker:***

```bash
# Replace the following with your actual Docker test command
docker exec -it <container_name> npm test
```
***Using npm:***

```bash
npm test
```
